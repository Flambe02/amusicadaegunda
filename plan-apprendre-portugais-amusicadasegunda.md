# A Música da Segunda
## Plan détaillé de développement de la section « Apprendre le portugais »

**Document de travail**  
**Version :** 1.0  
**Objectif :** transformer la section `/apprendre` en un véritable parcours d’apprentissage du portugais brésilien par la chanson.

---

# 1. Vision du produit

## 1.1 Positionnement

La section « Apprendre » doit devenir une expérience simple, ludique et régulière permettant à un francophone d’apprendre le portugais brésilien réellement parlé grâce aux chansons de **A Música da Segunda**.

La promesse centrale :

> Apprendre le portugais brésilien réel avec des chansons drôles, des expressions utiles et des leçons courtes.

Le produit ne doit pas chercher à devenir immédiatement une plateforme généraliste de langues. Il doit capitaliser sur trois forces distinctives :

- la musique ;
- l’humour ;
- la culture brésilienne contemporaine.

## 1.2 Public cible initial

Le lancement doit viser principalement :

- les francophones vivant au Brésil ;
- les francophones préparant un voyage ou une installation au Brésil ;
- les personnes qui comprennent déjà quelques mots mais ont du mal avec le portugais oral ;
- les niveaux A1 à B1.

Le produit pourra ensuite être adapté en anglais, espagnol ou italien, mais cette extension ne doit pas ralentir la première version.

## 1.3 Proposition de valeur

Le produit doit permettre à un utilisateur de :

1. découvrir une chanson ;
2. comprendre son contexte ;
3. apprendre plusieurs expressions utiles ;
4. écouter et répéter les phrases ;
5. jouer avec les paroles ;
6. chanter la chanson ;
7. revoir les mots appris ;
8. suivre sa progression.

# 2. Objectifs produit

## 2.1 Objectif principal

Faire en sorte qu’un utilisateur puisse terminer une première leçon en moins de 10 minutes et avoir la sensation d’avoir réellement appris cinq expressions de portugais.

## 2.2 Objectifs secondaires

## 2.3 Indicateurs clés

# 3. Principes pédagogiques

## 3.1 Une chanson égale une courte leçon

Chaque chanson doit proposer une expérience autonome de 7 à 12 minutes.

Une leçon ne doit pas chercher à tout expliquer. Elle doit sélectionner :

- 3 à 5 expressions principales ;
- 5 à 10 mots secondaires ;
- 1 ou 2 notions grammaticales simples ;
- 1 élément culturel brésilien.

## 3.2 Le portugais réel avant la grammaire exhaustive

La pédagogie doit privilégier :

- les expressions utilisées à l’oral ;
- les formulations familières ;
- les contractions ;
- le rythme de la langue ;
- les différences entre la traduction littérale et le sens réel.

La grammaire doit être expliquée uniquement lorsqu’elle aide à comprendre ou réutiliser une phrase.

## 3.3 Une progression basée sur la réussite

La première expérience doit être facile.

L’utilisateur doit obtenir rapidement :

- une réponse correcte ;
- une expression comprise ;
- une phrase reconnue ;
- une chanson terminée.

L’objectif est de renforcer la motivation avant d’augmenter la difficulté.

## 3.4 Répétition multimodale

Chaque expression importante doit idéalement être rencontrée sous plusieurs formes :

- dans la chanson ;
- dans la traduction ;
- dans une explication ;
- dans un exercice ;
- dans une activité de répétition ;
- dans une session de révision ultérieure.

# 4. Parcours utilisateur cible

## Étape 1. Découvrir la leçon

L’utilisateur voit une carte avec :

- le titre de la chanson ;
- le niveau ;
- la durée ;
- le thème ;
- les expressions principales ;
- un bouton « Commencer la leçon ».

### Exemple

**Eu Sou um Ovo**  
Niveau A1-A2  
Durée : 8 minutes  
Thème : nourriture, prix, frustration  
Expressions : `cadê`, `ninguém`, `ficar caro`, `não tem`, `isso é...?`

## Étape 2. Première écoute

L’utilisateur écoute la chanson ou un extrait sans traduction complète.

Objectif : comprendre l’idée générale.

À la fin, une question simple est proposée.

### Exemple

**De quoi parle principalement la chanson ?**

- d’un œuf devenu trop cher ;
- d’un restaurant ;
- d’une fête d’anniversaire.

## Étape 3. Compréhension ligne par ligne

Pour chaque passage important :

- ligne en portugais ;
- traduction française ;
- bouton écouter ;
- bouton ralentir ;
- explication courte ;
- bouton ajouter au carnet.

### Exemple

**Cadê meu sentido?**  
*Où est passé mon sens ?*

> `Cadê` est très fréquent à l’oral. Il correspond à `onde está?` ou `onde estão?`.

## Étape 4. Exercices

Les exercices doivent être courts et variés.

Formats recommandés :

- choix du mot entendu ;
- phrase à trous ;
- remise en ordre ;
- association portugais-français ;
- écoute et sélection ;
- vrai ou faux ;
- sélection de l’expression adaptée à une situation.

## Étape 5. Répétition et prononciation

Version initiale :

- écouter la phrase ;
- afficher le découpage rythmique ;
- enregistrer sa voix ;
- réécouter ;
- recommencer.

Version future :

- analyse du rythme ;
- détection des mots prononcés ;
- score de prononciation ;
- conseils phonétiques ;
- comparaison audio.

## Étape 6. Karaoké final

L’utilisateur chante la chanson entière avec :

- paroles synchronisées ;
- traduction activable ;
- vitesse normale ou lente ;
- mode ligne ou mot ;
- option voix originale réduite.

## Étape 7. Résultat

L’écran final doit indiquer :

- leçon terminée ;
- nombre d’expressions apprises ;
- score des exercices ;
- nombre de phrases répétées ;
- temps passé ;
- prochaine action recommandée.

Actions proposées :

- revoir les mots ;
- refaire le karaoké ;
- continuer avec une autre chanson ;
- créer un compte ;
- recevoir la prochaine leçon.

## 5.1 Hero principal

### Titre proposé

**Aprenda português brasileiro com música e humor**

**Como funciona**

## 5.2 Bloc « Comment ça marche »

Présenter trois étapes :

1. **Escute**  
   Découvre la chanson et son contexte.

2. **Entenda**  
   Comprends les paroles, les expressions et la culture.

3. **Cante e pratique**  
   Joue, répète et chante.

## 5.3 Cartes de leçons

Chaque carte doit afficher :

- titre ;
- illustration ;
- niveau ;
- durée ;
- thème ;
- expressions apprises ;
- progression ;
- bouton principal.

### États possibles

- nouvelle leçon ;
- non commencée ;
- en cours ;
- terminée ;
- révision disponible.

## 5.4 Aperçu de l’expérience

Ajouter un exemple interactif directement sur la page :

- une ligne en portugais ;
- sa traduction ;
- un bouton audio ;
- une petite explication ;
- une question à choix multiple.

L’objectif est de montrer immédiatement le produit au lieu de seulement le décrire.

## 5.5 Bloc progression

Pour un utilisateur non connecté :

- progression enregistrée localement ;
- nombre de leçons commencées ;
- nombre d’expressions apprises ;
- temps d’apprentissage.

Pour un utilisateur connecté :

- synchronisation Supabase ;
- historique ;
- carnet ;
- révisions ;
- série hebdomadaire.

## 5.6 Formulaire d’inscription

Le formulaire doit arriver après la démonstration ou après la première leçon.

Texte proposé :

> Receba uma nova aula quando ela sair.

Champs minimum :

- prénom ;
- email ;
- niveau estimé ;
- objectif principal.

# Phase 4. Révision espacée légère

## Objectif

Aider l’utilisateur à mémoriser les expressions sur plusieurs semaines.

## Règle initiale

- première révision après 1 jour ;
- deuxième après 3 jours ;
- troisième après 7 jours ;
- quatrième après 21 jours.

## Activités de révision

- retrouver la traduction ;
- compléter la phrase ;
- écouter et identifier ;
- choisir la bonne situation ;
- répéter à voix haute.

## Critères d’acceptation

- la prochaine date de révision est calculée ;
- une session dure moins de 5 minutes ;
- les erreurs rapprochent la prochaine révision ;
- les réussites augmentent l’intervalle ;
- la session utilise les expressions réellement apprises.

# 12. Tests utilisateurs

## Taille du premier panel

10 à 20 francophones.

Profils recherchés :

- débutant total ;
- niveau A1-A2 ;
- expatrié au Brésil ;
- voyageur régulier ;
- amateur de musique ;
- utilisateur peu technophile.

## Questions à valider

- la promesse est-elle comprise ?
- l’utilisateur sait-il où cliquer ?
- comprend-il le fonctionnement de la leçon ?
- termine-t-il la première écoute ?
- comprend-il les explications ?
- trouve-t-il les exercices trop simples ou trop difficiles ?
- utilise-t-il le carnet ?
- veut-il continuer ?
- revient-il après quelques jours ?

## Seuils de validation initiaux

Objectifs indicatifs :

- 50 % des visiteurs cliquent sur une leçon ;
- 70 % des démarreurs terminent les trois premières étapes ;
- 50 % terminent la leçon ;
- 30 % sauvegardent au moins une expression ;
- 20 % créent un compte ou laissent leur email ;
- 20 % reviennent dans les 7 jours.

# 13. Modèle éditorial hebdomadaire

## Option recommandée

### Lundi

Publication de la chanson.

### Mercredi

Publication de la mini-leçon avec les expressions principales.

### Vendredi

Quiz, défi karaoké ou révision.

Ce rythme permet de transformer une chanson en plusieurs rendez-vous et d’augmenter la durée de vie du contenu.

## Deux niveaux de contenu

### Mini-leçon

- 3 expressions ;
- 3 exercices ;
- 5 minutes ;
- production rapide.

### Leçon complète

- 5 expressions ;
- 5 à 8 exercices ;
- prononciation ;
- karaoké ;
- 8 à 12 minutes.

Toutes les chansons ne doivent pas nécessairement recevoir immédiatement une leçon complète.

## Version gratuite

- accès à plusieurs leçons ;
- traduction ligne par ligne ;
- exercices simples ;
- karaoké ;

# 19. Décision stratégique finale

La priorité n’est pas de créer immédiatement un grand catalogue.

La priorité est de construire une première leçon excellente, courte et mémorable.

La séquence recommandée est :

> Une excellente leçon, puis la progression, le carnet, les révisions, une deuxième leçon, l’industrialisation du back-office, puis le rythme hebdomadaire.

Le succès du produit doit être jugé sur une question simple :

> Est-ce qu’un utilisateur apprend réellement plusieurs expressions, termine la leçon et revient la semaine suivante ?

Si la réponse devient oui, **A Música da Segunda** pourra évoluer d’un projet musical avec une dimension pédagogique vers une véritable plateforme d’apprentissage du portugais brésilien par la musique et la culture.
